# Tension Simulation (Mass-Spring Model) in Go

Go言語（Golang）と2Dゲームエンジン「Ebitengine」を使用して開発された、物理的な張力（テンション）を視覚化するリアルタイムシミュレーターです。
質点・バネモデル（Mass-Spring System）とベルレ積分（Verlet Integration）を用いて、ロープが引っ張られた際のエネルギー伝播や張力の変化をリアルタイムに計算・描画します。

## 🚀 特徴

- **リアルタイム物理演算:** 重力、空気抵抗（ダンピング）、およびバネの復元力（フックの法則）をシミュレート。
- **高精度サブステップ処理:** 1フレーム内に複数回の拘束解決（Sub-steps）を行うことで、ゴムのような伸びを抑えた「頑丈な糸」の挙動を実現。
- **張力の視覚化（カラーライズ）:** 自然長から糸が引き伸ばされ、張力が高くなるほど、白 ➔ 黄 ➔ 赤へとラインの色が動的に変化。
- **インタラクティブ操作:** ロープの一番下の端（緑色のジョイント）をマウスでドラッグして、自由に振り回したり引っ張ったりすることが可能。

## 🛠️ 動作環境

- Go 1.18 以上（推奨）
- Ebitengine (v2)

## 📦 セットアップと実行方法

1. **プロジェクトディレクトリの作成と移動**
```bash
   mkdir hooks-law
   cd hooks-law
Go モジュールの初期化

Bash
   go mod init tension_sim
Ebitengine (v2) のインストール

Bash
   go get [github.com/hajimehoshi/ebiten/v2](https://github.com/hajimehoshi/ebiten/v2)
実行
main.go にソースコードを保存し、以下のコマンドを実行します。

Bash
   go run main.go
🎮 操作方法
マウスの左クリック＆ドラッグ: ロープの一番下にある緑色の点にカーソルを合わせて左クリックしながら動かすと、ロープを引っ張ることができます。

固定点: 一番上の赤色の点は空間に固定されています。

🔍 物理パラメーターの調整（カスタマイズ）
main.go の上部にある定数（const）を書き換えることで、シミュレーションの挙動を簡単に変更できます。

Go
const (
	screenWidth  = 640
	screenHeight = 480
	gravity      = 0.5   // 重力の強さ（大きくするとロープが重くなります）
	damping      = 0.01  // 空気抵抗（0に近づくほど宇宙空間のように揺れが残ります）
	subSteps     = 8     // 1フレーム内の計算回数（増やすとロープの剛性が上がり硬くなります）
)
